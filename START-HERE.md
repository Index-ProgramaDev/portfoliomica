## ❓ DÚVIDAS COMUNS

### "E se eu quiser mudar alguma coisa no site?"

1. Edite os arquivos (principalmente `src/routes/index.tsx`)
2. Teste localmente: `npm run dev`
3. Commit: `git add . && git commit -m "Descrição da mudança"`
4. Push: `git push`
5. O Vercel atualiza automaticamente! 🎉

### "Como adiciono mais fotos/vídeos?"

1. Coloque os arquivos em `src/assets/`
2. Crie um arquivo `.asset.json` correspondente com a URL
3. Importe no `index.tsx`
4. Use como nos exemplos existentes

### "Não tenho Git instalado"

Leia: `GIT-GUIDE.md` → Passo 1

### "Deu erro no build"

```bash
# Deletar node_modules e reinstalar
Remove-Item -Recurse -Force node_modules
npm install
npm run build
```
