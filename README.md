## 📝 Sobre o Projeto

Portfólio digital das práticas de laboratório sobre o sistema digestório, focando na identificação do amido nos alimentos e na ação da ptialina (amilase salivar).

## 🚀 Deploy no Vercel

### Pré-requisitos

1. Conta no [Vercel](https://vercel.com)
2. Instalar o [Vercel CLI](https://vercel.com/docs/cli) (opcional)

### Deploy pelo Site

1. Acesse [vercel.com](https://vercel.com) e faça login
2. Clique em "Add New..." → "Project"
3. Importe o repositório do GitHub ou faça upload dos arquivos
4. O Vercel detectará automaticamente as configurações
5. Clique em "Deploy"

### Deploy pela CLI

```bash
# Instalar Vercel CLI
npm i -g vercel

# Na pasta do projeto, execute:
vercel

# Para produção:
vercel --prod
```

## 🛠️ Desenvolvimento Local

```bash
# Instalar dependências
npm install

# Rodar em modo desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview da build
npm run preview
```
